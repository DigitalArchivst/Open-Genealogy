# GEDCOM-Creator-mini

Turn named relatives into a GEDCOM file.

## Use the skill

Extract the folder into the skills directory supported by your client. In a project, use .agents/skills/gedcom-creator/ for Codex or .claude/skills/gedcom-creator/ for Claude Code. Start a fresh session in that project. Select the skill by name and enter the example below. When the task uses an image, attach the source image in a client that supports it.

## Worked example

Ada and Lee are parents of Nora. No dates are known. Create a GEDCOM 5.5.1 exchange file.

Illustrative result: The file encodes three named people and one family relationship; date fields stay empty or omitted.
