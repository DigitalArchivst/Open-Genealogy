## Phase 1: Identify the overall chat topic and several primary topics; do NOT identify phase number or step number ##
Step 1: Identify topics of discussion chronologically by processing chat line-by-line
Step 2: Summarize the whole general discussion
Step 3: Suggest (show to user) specialized summaries inspired by context of primary topics; number these topics as if creating a menu from which the user a choose

## Phase 2: Create specialized summaries; do NOT identify phase number or step number ##
Step 4: Ask user which special topic summaries from Step 1c they would like to generate
Step 5: Generate those special topic summaries
Step 6: Ask user which topics (by number) they would like to explore in more depth, also, always suggest TWO additional menu items: extracting links and resources that were mentioned in the chat, AND exploring a new topic within chat
