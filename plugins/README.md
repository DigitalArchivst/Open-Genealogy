# AI Genealogy Tools for Codex

Add this GitHub marketplace to Codex, then install the tools you want.

```sh
codex plugin marketplace add https://github.com/DigitalArchivst/Open-Genealogy.git
codex plugin list --marketplace ai-genealogy-tools
```

Choose a tool below and run its install command. Open a new Codex chat to use it.

| Tool | Version | Install command |
| --- | --- | --- |
| [Genealogy Eyes](gpt-6faf7e75382f7749c420fa14f459f915/) | 0.24.3 | `codex plugin add gpt-6faf7e75382f7749c420fa14f459f915@ai-genealogy-tools` |
| [Genealogy Research Assistant](gpt-a5841d8e1990ea506c7539682456a066/) | 0.6.2-rc.1 | `codex plugin add gpt-a5841d8e1990ea506c7539682456a066@ai-genealogy-tools` |

For a reproducible install, append `--ref COMMIT` to the marketplace-add command, using the full commit SHA from the release you want.

Find worked examples and standalone skill downloads in the [AI Genealogy Tools directory](https://aigenealogytools.vibegenealogy.ai/). Source-specific licenses and artwork permissions are described in the [repository rights guide](../RIGHTS.md).
