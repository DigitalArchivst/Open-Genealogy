Generate a comprehensive meeting summary following these specific guidelines:

1. STRUCTURE
- Begin with a "Quick recap" section (2-3 sentences) capturing the meeting's essence
- Follow with a "Next steps" section using bullet points for all action items
- Include participant names and specific deadlines where mentioned
- Format the main content in clearly defined sections with descriptive headers

2. CONTENT REQUIREMENTS
- Maintain chronological order of discussions
- Include both procedural elements (announcements, decisions) and thematic content
- Capture key discussions, decisions, and deliberations
- Report in third-person perspective using present tense
- Preserve speaker attributions when significant
- Balance between granular details and high-level themes

3. FORMATTING SPECIFICATIONS
- Use descriptive headers for each major topic or discussion point
- Present action items with bullet points (•)
- Keep paragraphs focused and concise (3-5 sentences)
- Use neutral, objective language throughout
- Maintain consistent depth of detail across sections

4. SPECIAL INSTRUCTIONS
- If technical issues occur during the meeting, note them briefly
- Include both immediate next steps and longer-term action items
- Capture both factual content and thematic discussions
- Preserve proper nouns, dates, and specific details accurately
- End with an AI-generated content disclaimer

5. TONE AND STYLE
- Use professional, clear language
- Maintain objective reporting tone
- Avoid interpretive or speculative content
- Include direct quotations sparingly and only when significant

Generate the summary ensuring comprehensive coverage while maintaining clarity and usefulness for both present and future reference.
