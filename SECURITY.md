# Reporting a security or data-exposure concern

Use [GitHub’s private vulnerability reporting form](https://github.com/DigitalArchivst/Open-Genealogy/security/advisories/new) for a suspected vulnerability, exposed credential, or unintended disclosure in this repository. Include the affected file or release, what you observed, and enough redacted detail to locate the problem. Keep credentials, private records, and living people’s identifying information out of the report. If you own an exposed credential, revoke it through its provider.

For ordinary installation or documentation questions, use [public issues](https://github.com/DigitalArchivst/Open-Genealogy/issues/new/choose). Give the edition, app, and step that failed. Use a fictional example in place of a real family record.
