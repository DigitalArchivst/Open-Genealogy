# Genealogy Summarizer

Summarize a family-history document.

## Use the skill

Extract the folder into the skills directory supported by your client. In a project, use .agents/skills/genealogy-summarizer/ for Codex or .claude/skills/genealogy-summarizer/ for Claude Code. Start a fresh session in that project. Select the skill by name and enter the example below. When the task uses an image, attach the source image in a client that supports it.

## Worked example

A fictional notice says “Jane Allen visited Mrs. L. Gray on Monday.” Summarize it for a research log.

Illustrative result: The notice reports a Monday visit by Jane Allen to Mrs. L. Gray. It supplies no calendar date or relationship.
