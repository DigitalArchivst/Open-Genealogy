# Steve's Council-of-Experts (Mixture of Experts)

Compare expert perspectives on a decision.

## Use the skill

Extract the folder into the skills directory supported by your client. In a project, use .agents/skills/council-of-experts-mixture-of-experts/ for Codex or .claude/skills/council-of-experts-mixture-of-experts/ for Claude Code. Start a fresh session in that project. Select the skill by name and enter the example below. When the task uses an image, attach the source image in a client that supports it.

## Worked example

Compare whether a historical society should digitize three fragile letters or one large newspaper first. Present the competing perspectives.

Illustrative result: A conservator can prioritize fragility while an access specialist prioritizes reach. State what condition and demand data are missing.
