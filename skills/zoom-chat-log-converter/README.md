# Steve's Zoom Chat Log Converter

Track a discussion through a Zoom chat.

## Use the skill

Extract the folder into the skills directory supported by your client. In a project, use .agents/skills/zoom-chat-log-converter/ for Codex or .claude/skills/zoom-chat-log-converter/ for Claude Code. Start a fresh session in that project. Select the skill by name and enter the example below. When the task uses an image, attach the source image in a client that supports it.

## Worked example

10:00 Pat: Hall booked. 10:02 Lee: Chairs? 10:04 Pat: Hall reopened the booking. Trace the discussion.

Illustrative result: The hall moves from booked to uncertain by 10:04. The chair question remains unanswered.
