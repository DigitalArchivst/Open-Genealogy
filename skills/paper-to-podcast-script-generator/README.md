# Steve's Paper to Podcast Script Generator

Adapt a paper into a two-host podcast script.

## Use the skill

Extract the folder into the skills directory supported by your client. In a project, use .agents/skills/paper-to-podcast-script-generator/ for Codex or .claude/skills/paper-to-podcast-script-generator/ for Claude Code. Start a fresh session in that project. Select the skill by name and enter the example below. When the task uses an image, attach the source image in a client that supports it.

## Worked example

Adapt this finding for two hosts: “Only 12 residents returned the voluntary survey. Eight supported a Saturday picnic.”

Illustrative result: One host presents 8 of 12 responses. The other explains why these responses do not establish community-wide support.
