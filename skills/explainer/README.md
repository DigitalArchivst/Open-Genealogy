# Steve's Explainer

Explain one idea at two reading levels.

## Use the skill

Extract the folder into the skills directory supported by your client. In a project, use .agents/skills/explainer/ for Codex or .claude/skills/explainer/ for Claude Code. Start a fresh session in that project. Select the skill by name and enter the example below. When the task uses an image, attach the source image in a client that supports it.

## Worked example

Explain why a census age can vary between records to a seventh grader and a college freshman.

Illustrative result: The first version introduces the idea in ordinary language. The second discusses informants and timing, preserving the same underlying facts.
