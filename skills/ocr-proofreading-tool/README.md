# Steve's OCR & Proofreading Tool

Transcribe a page and produce a clean reading copy.

## Use the skill

Extract the folder into the skills directory supported by your client. In a project, use .agents/skills/ocr-proofreading-tool/ for Codex or .claude/skills/ocr-proofreading-tool/ for Claude Code. Start a fresh session in that project. Select the skill by name and enter the example below. When the task uses an image, attach the source image in a client that supports it.

## Worked example

Attach the fictional picnic notice. Return the wording and a clean reading copy.

Illustrative result: The transcription preserves the advertised performer and the notice's wording. Any editorial corrections appear in a separate copy.
