# Steve's Image Citation Builder

Cite an edited historical photograph.

## Use the skill

Extract the folder into the skills directory supported by your client. In a project, use .agents/skills/image-citation-builder/ for Codex or .claude/skills/image-citation-builder/ for Claude Code. Start a fresh session in that project. Select the skill by name and enter the example below. When the task uses an image, attach the source image in a client that supports it.

## Worked example

I scanned a photograph from the Gray family album and increased contrast. Draft a citation and tell me what's missing.

Illustrative result: Credit the album and the scan; identify the contrast adjustment and ask about photographer, date and custody.
