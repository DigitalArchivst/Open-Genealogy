# Steve's Chatlog Analyzer

Analyze classroom participation and shared resources.

## Use the skill

Extract the folder into .agents/skills/ for Codex or .claude/skills/ for Claude Code inside your project. Open a fresh session and select the skill by name.

## Worked example

Analyze this fictional class chat for shared resources and teaching follow-up. 10:00 A: The class glossary helped. 10:02 B: Where is the practice worksheet? 10:03 A: In the course folder. 10:04 C: Captions froze; I missed the instructions.

Expected reading: Identify the glossary and course-folder worksheet, the captions failure, and a practical teaching follow-up. Preserve what was actually shared and avoid inventing a URL.
