# Steve's Cemetery Transcriber

Transcribe and describe a gravestone.

## Use the skill

Extract the folder into the skills directory supported by your client. In a project, use .agents/skills/cemetery-transcriber/ for Codex or .claude/skills/cemetery-transcriber/ for Claude Code. Start a fresh session in that project. Select the skill by name and enter the example below. When the task uses an image, attach the source image in a client that supports it.

## Worked example

Given a marker visibly reading “ADA / 1870–19?4,” transcribe those lines and identify the uncertain character.

Illustrative result: ADA / 1870–19?4. The third digit of the closing year is unreadable; a clearer image could resolve it.
