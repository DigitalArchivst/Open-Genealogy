# Steve's Summarizer

Summarize the main argument of a text.

## Use the skill

Extract the folder into .agents/skills/ for Codex or .claude/skills/ for Claude Code inside your project. Open a fresh session and select the skill by name.

## Worked example

Summarize this fictional library memo: The pilot added two evening hours on Fridays. Twelve patrons used them during the first month. The board will review costs before extending the pilot.

Expected reading: Preserve the two evening hours, the twelve patrons and the first-month period. Extension remains conditional on a cost review.
