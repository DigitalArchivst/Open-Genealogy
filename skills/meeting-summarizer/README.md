# Meeting Summarizer

Recover decisions and owners from a meeting.

## Use the skill

Extract the folder into the skills directory supported by your client. In a project, use .agents/skills/meeting-summarizer/ for Codex or .claude/skills/meeting-summarizer/ for Claude Code. Start a fresh session in that project. Select the skill by name and enter the example below. When the task uses an image, attach the source image in a client that supports it.

## Worked example

Minutes say: “Pat will book the hall by Thursday. The group discussed chairs but made no decision.” Summarize actions.

Illustrative result: Pat owns the hall booking, due Thursday. Chair arrangements remain open.
