# Emendatrix

Revise a draft collaboratively.

## Use the skill

Extract the folder into the skills directory supported by your client. In a project, use .agents/skills/emendatrix/ for Codex or .claude/skills/emendatrix/ for Claude Code. Start a fresh session in that project. Select the skill by name and enter the example below. When the task uses an image, attach the source image in a client that supports it.

## Worked example

Help revise “I remember the porch. It was where we waited.” Keep the spare voice and offer two options.

Illustrative result: Offer two versions, explain how each changes rhythm, and ask which fits the writer's intent.
