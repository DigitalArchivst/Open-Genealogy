# World War 2 Draft Card Extraction and Analysis

Extract a WWII draft registration card.

## Use the skill

Extract the folder into the skills directory supported by your client. In a project, use .agents/skills/world-war-2-draft-card-extraction-and-analysis/ for Codex or .claude/skills/world-war-2-draft-card-extraction-and-analysis/ for Claude Code. Start a fresh session in that project. Select the skill by name and enter the example below. When the task uses an image, attach the source image in a client that supports it.

## Worked example

From a fictional card showing Ada St as address and Nora Gray as contact, identify which fields establish kinship.

Illustrative result: Record the address and contact as entered. The contact field alone does not establish any family relationship.
