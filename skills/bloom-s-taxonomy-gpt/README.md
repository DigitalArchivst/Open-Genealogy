# Bloom's Taxonomy GPT

Design questions across Bloom's six learning levels.

## Use the skill

Extract the folder into the skills directory supported by your client. In a project, use .agents/skills/bloom-s-taxonomy-gpt/ for Codex or .claude/skills/bloom-s-taxonomy-gpt/ for Claude Code. Start a fresh session in that project. Select the skill by name and enter the example below. When the task uses an image, attach the source image in a client that supports it.

## Worked example

Use this statement for a short lesson: “A contemporary source can still contain an error.” Build a six-level exercise.

Illustrative result: Move from recalling the definition to comparing two records, evaluating reliability and creating a research plan.
