# Lingua Maven

Choose the right word for an audience.

## Use the skill

Extract the folder into the skills directory supported by your client. In a project, use .agents/skills/lingua-maven/ for Codex or .claude/skills/lingua-maven/ for Claude Code. Start a fresh session in that project. Select the skill by name and enter the example below. When the task uses an image, attach the source image in a client that supports it.

## Worked example

Neighbors are requested to attend the picnic. Which fits a friendly optional invitation: invited, encouraged, or expected?

Illustrative result: “Invited” sounds welcoming and leaves attendance optional. “Expected” suggests an obligation.
