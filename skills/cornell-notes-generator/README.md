# Steve's Cornell Notes Generator

Turn a lecture into Cornell study notes.

## Use the skill

Extract the folder into the skills directory supported by your client. In a project, use .agents/skills/cornell-notes-generator/ for Codex or .claude/skills/cornell-notes-generator/ for Claude Code. Start a fresh session in that project. Select the skill by name and enter the example below. When the task uses an image, attach the source image in a client that supports it.

## Worked example

Lesson: A source is a container. Information is what the source says. Evidence answers a specific question. Make Cornell notes.

Illustrative result: Cue: What turns information into evidence? Notes: Its relevance to a particular question. Summary: A source contains information evaluated against a question.
