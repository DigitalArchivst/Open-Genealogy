# Steve's Data Visualizer

Turn a small table into a labeled chart.

## Use the skill

Extract the folder into the skills directory supported by your client. In a project, use .agents/skills/data-visualizer/ for Codex or .claude/skills/data-visualizer/ for Claude Code. Start a fresh session in that project. Select the skill by name and enter the example below. When the task uses an image, attach the source image in a client that supports it.

## Worked example

Chart weekly registrations: W1 3, W2 7, W3 4, W4 9. Include the counts and labels.

Illustrative result: A chart uses four labeled weeks, counts 3, 7, 4, 9 and a registration-count axis.
