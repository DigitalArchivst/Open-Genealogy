# Email Helper

Turn an email into a task list and draft reply.

## Use the skill

Extract the folder into the skills directory supported by your client. In a project, use .agents/skills/email-helper/ for Codex or .claude/skills/email-helper/ for Claude Code. Start a fresh session in that project. Select the skill by name and enter the example below. When the task uses an image, attach the source image in a client that supports it.

## Worked example

A committee asks for the hall booking, chair count and flyer. Hall booked; flyer Friday. What do I owe them?

Illustrative result: Confirm the booking, ask for the chair count, and say the flyer will be ready Friday.
