# Steve's Tutor Tool

Learn a skill through one question at a time.

## Use the skill

Extract the folder into the skills directory supported by your client. In a project, use .agents/skills/tutor-tool/ for Codex or .claude/skills/tutor-tool/ for Claude Code. Start a fresh session in that project. Select the skill by name and enter the example below. When the task uses an image, attach the source image in a client that supports it.

## Worked example

Teach me how to distinguish a source from a claim. Start with one short practice question.

Illustrative result: Present one simple scenario and wait for the learner's answer before evaluating or advancing.
