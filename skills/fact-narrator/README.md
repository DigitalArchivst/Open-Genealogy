# Steve's Fact Narrator

Turn labeled facts into a sourced narrative.

## Use the skill

Extract the folder into the skills directory supported by your client. In a project, use .agents/skills/fact-narrator/ for Codex or .claude/skills/fact-narrator/ for Claude Code. Start a fresh session in that project. Select the skill by name and enter the example below. When the task uses an image, attach the source image in a client that supports it.

## Worked example

F1: a notice named Clara as the violinist. F2: a later account called her the pianist. Write a short narrative.

Illustrative result: The notice identified Clara as the violinist. A later account called her the pianist. The instrument remains uncertain.
