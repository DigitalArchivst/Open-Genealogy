# Steve's Semantic Similarity Analysis

Compare the meaning of two passages.

## Use the skill

Extract the folder into the skills directory supported by your client. In a project, use .agents/skills/semantic-similarity-analysis/ for Codex or .claude/skills/semantic-similarity-analysis/ for Claude Code. Start a fresh session in that project. Select the skill by name and enter the example below. When the task uses an image, attach the source image in a client that supports it.

## Worked example

Compare “The club will meet Friday at 5” with “The club gathers at five on Friday.” Explain the shared meaning.

Illustrative result: Both describe a club meeting Friday at five. Score high similarity and point to the corresponding elements.
