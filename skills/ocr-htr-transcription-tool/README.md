# Steve's OCR/HTR Transcription Tool

Make a diplomatic transcription of handwriting.

## Use the skill

Extract the folder into the skills directory supported by your client. In a project, use .agents/skills/ocr-htr-transcription-tool/ for Codex or .claude/skills/ocr-htr-transcription-tool/ for Claude Code. Start a fresh session in that project. Select the skill by name and enter the example below. When the task uses an image, attach the source image in a client that supports it.

## Worked example

Transcribe a handwritten line reading “rec'd 3 yds” where the final letter is uncertain. Preserve abbreviations.

Illustrative result: The transcript keeps “rec'd” and marks the imperfect reading. A normalized expansion, if supplied, appears separately.
