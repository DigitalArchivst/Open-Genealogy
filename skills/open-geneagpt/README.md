# Open GeneaGPT

Start a family-history research plan.

## Use the skill

Extract the folder into .agents/skills/ for Codex or .claude/skills/ for Claude Code inside your project. Open a fresh session and select the skill by name.

## Worked example

In this fictional family, Nell Hart’s granddaughter remembers that Nell married Tom Dale somewhere in Ohio. Their first known child was born in 1914. I have no county or marriage record. What could I do first, and why? Please give me a usable plan.

Expected reading: A focused clarifying question or explicit assumption, a concrete first search, a way to narrow place and date, and four distinct choices for continuing. The child’s birth year does not establish the wedding date. No invented ceremony, repository result, or citation.
