# Steve's Photo Tool

Critique a photograph's composition.

## Use the skill

Extract the folder into the skills directory supported by your client. In a project, use .agents/skills/photo-tool/ for Codex or .claude/skills/photo-tool/ for Claude Code. Start a fresh session in that project. Select the skill by name and enter the example below. When the task uses an image, attach the source image in a client that supports it.

## Worked example

Review an image with a subject near the frame edge and a diagonal path leading away. Suggest two possible crops.

Illustrative result: Describe how the eye follows the path and how each crop would change emphasis. Tie each suggestion to a visible feature.
