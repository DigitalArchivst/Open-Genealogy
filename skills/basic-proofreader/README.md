# Steve's Basic Proofreader

Proofread with the fewest changes.

## Use the skill

Extract the folder into the skills directory supported by your client. In a project, use .agents/skills/basic-proofreader/ for Codex or .claude/skills/basic-proofreader/ for Claude Code. Start a fresh session in that project. Select the skill by name and enter the example below. When the task uses an image, attach the source image in a client that supports it.

## Worked example

Correct only mechanical errors: “Their bringing there own chairs.”

Illustrative result: “They're bringing their own chairs.” The tone and meaning stay intact.
