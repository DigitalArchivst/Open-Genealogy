# PDF Conversion Tool

Convert a PDF into an editable document.

## Use the skill

Extract the folder into .agents/skills/ for Codex or .claude/skills/ for Claude Code inside your project. Open a fresh session and select the skill by name.

Use the included examples/accession-list.pdf for the worked example. Install compatible local Python libraries from a source you trust. DOCX is the file format exercised in this edition.

## Worked example

Convert this PDF to an editable DOCX. Keep the reading order and table structure, and mark anything you cannot read. Return the file.

Expected reading: The DOCX opens with a real four-row three-column table containing B-07/Oral histories/4, B-12/Parish maps/11 and B-19/School books/3. Preserve identifiers, title and note.
