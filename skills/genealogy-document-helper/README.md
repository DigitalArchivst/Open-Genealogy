# Genealogy Document Helper

Create a catalog entry for an archival item.

## Use the skill

Extract the folder into the skills directory supported by your client. In a project, use .agents/skills/genealogy-document-helper/ for Codex or .claude/skills/genealogy-document-helper/ for Claude Code. Start a fresh session in that project. Select the skill by name and enter the example below. When the task uses an image, attach the source image in a client that supports it.

## Worked example

Catalog an unsigned postcard headed “Mill Street, May 1912,” with a penciled archive ID P-17.

Illustrative result: Object: postcard. Written date: May 1912. Identifier: P-17. Creator and recipient remain unknown.
