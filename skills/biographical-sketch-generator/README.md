# Biographical Sketch Generator

Write a short birthday radio biography.

## Use the skill

Extract the folder into the skills directory supported by your client. In a project, use .agents/skills/biographical-sketch-generator/ for Codex or .claude/skills/biographical-sketch-generator/ for Claude Code. Start a fresh session in that project. Select the skill by name and enter the example below. When the task uses an image, attach the source image in a client that supports it.

## Worked example

Using only these fictional facts, write a birthday radio sketch: Ada Green was born 4 May 1900, taught at River School, and retired in 1959.

Illustrative result: A spoken birthday segment connects Ada's teaching and retirement with her May 4 birthday, using only the supplied facts.
