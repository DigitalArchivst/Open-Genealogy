# Steve's Facts Extractor

Extract facts and claims from a source.

## Use the skill

Extract the folder into the skills directory supported by your client. In a project, use .agents/skills/facts-extractor/ for Codex or .claude/skills/facts-extractor/ for Claude Code. Start a fresh session in that project. Select the skill by name and enter the example below. When the task uses an image, attach the source image in a client that supports it.

## Worked example

A 1940 newspaper says Ada Gray visited Nora Gray, “said to be her cousin.” Extract the facts and claims.

Illustrative result: The visit is reported by the newspaper. Cousinship is an attributed claim. A shared surname alone establishes no relationship.
