# Steve's Clarity Checker

Find places where a draft loses its reader.

## Use the skill

Extract the folder into the skills directory supported by your client. In a project, use .agents/skills/clarity-checker/ for Codex or .claude/skills/clarity-checker/ for Claude Code. Start a fresh session in that project. Select the skill by name and enter the example below. When the task uses an image, attach the source image in a client that supports it.

## Worked example

Our draft says “Because it was clear, this proves it.” Explain what a reader needs before the conclusion.

Illustrative result: Identify the two vague uses of “it,” ask which record and claim are meant, and suggest naming the evidence.
